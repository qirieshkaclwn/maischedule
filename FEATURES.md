# Возможности и функционал сервиса MAI Schedule

Комплексный обзор возможностей сервиса синхронизации расписания Московского авиационного института (МАИ), Telegram Mini App, бота и интеграции с календарями.

---

## 1. Telegram Mini App (Web App)

Интерактивное веб-приложение для мгновенного просмотра расписания прямо внутри мессенджера Telegram.

### Быстродействие и Time-to-Content
- **Локальный кэш (Stale-While-Revalidate / SWR)**:
  - При повторном открытии расписание отображается мгновенно (<5 мс) из локального хранилища `localStorage`.
  - Отсутствует мерцание интерфейса и блокирующий скелетон при наличии сохраненной копии.
  - Обновление данных происходит в фоновом режиме: при получении свежего расписания экран тихо перерисовывается.
- **Локальный хостинг SDK Telegram (`/static/telegram-web-app.js`)**:
  - Официальный скрипт `telegram-web-app.js` встроен в бинарный файл сервиса и отдается непосредственно с сервера приложения.
  - Устранена проблема 21-22 секундного сетевого таймаута TCP SYN, возникавшая при синхронной загрузке с CDN `telegram.org` через провайдеров в РФ из-за фильтрации DPI.
  - Скрипт кэшируется браузером на максимальный срок (`Cache-Control: public, max-age=31536000, immutable`) и сжимается Gzip до 19 КБ.
- **Неблокирующая синхронизация профиля**:
  - Запрос сверки группы и статуса уведомлений пользователя в боте (`syncUserData`) вынесен в асинхронный фоновый вызов и не блокирует начальную отрисовку интерфейса.
- **Отложенная загрузка каталога групп**:
  - Список всех 1000+ академических групп МАИ (125 КБ) не загружается в критическом пути запуска.
  - Запрос откладывается либо инициируется по требованию при открытии модального окна выбора группы, а результат сохраняется в `sessionStorage`.

### Интерфейс и пользовательский опыт
- **Режимы отображения**:
  - Быстрые вкладки: "Сегодня", "Завтра", "Вся неделя".
  - Горизонтальная лента дней текущей недели с возможностью выбора любого конкретного дня.
- **Карточки занятий**:
  - Цветовая полоса и бейдж типа занятия: лекция (синий), практическое занятие (зеленый), лабораторная работа (фиолетовый), прочие мероприятия (оранжевый).
  - Время проведения пары, название предмета, номера аудиторий и имена преподавателей.
- **Выбор учебной группы**:
  - Всплывающая панель (Drawer) с живым поиском по номеру группы или фрагменту названия (например, "309БВ" или "М14О").
  - Индикация номера курса для каждой группы.
- **Интеграция с темой оформления**:
  - Автоматическая адаптация к светлой и темной теме интерфейса Telegram.

### Мониторинг доступности внешнего сервера МАИ
- **Красный индикатор сбоя (Warning Badge)**:
  - Отображается в шапке приложения, если внешний сервер `public.mai.ru` не отвечает или данные не обновлялись длительное время.
- **Диалоговое окно статуса**:
  - Показывает длительность простоя (сколько времени сервер не отдает данные).
  - Точное время начала сбоя.
  - Время последней сохраненной копии расписания.
  - Детали сетевой ошибки при ее наличии.

## 2. Календарная синхронизация (Webcal / iCalendar)

Синхронизация расписания занятий с системными календарями на любых устройствах.

- **Поддержка протокола Webcal (RFC 5545)**:
  - Автоматическая подписка на календарь для Apple Calendar (iOS, iPadOS, macOS), Google Calendar и Outlook.
  - Обновление расписания в фоновом режиме по расписанию календаря устройства.
- **Детерминированные идентификаторы событий (UID)**:
  - Стабильный расчет UID на основе группы, даты, времени и названия предмета.
  - Предотвращает дублирование событий в календаре при обновлениях.
- **Встроенные напоминания (VALARM)**:
  - Настраиваемое время заблаговременного напоминания до начала пары (по умолчанию 15 минут).
- **Часовой пояс**:
  - Строгая привязка к часовому поясу Europe/Moscow (UTC+3) без смещения времени при путешествиях.
- **Удобное подключение**:
  - Кнопка в Mini App "Добавить в Apple Calendar" формирует ссылку с протоколом `webcal://` для настройки в один клик на iPhone.
  - Кнопка быстрого копирования прямой HTTPS-ссылки на `.ics` файл.

## 3. Отслеживание изменений (Diff Engine) и Telegram-бот

Автоматический мониторинг изменений в учебных планах МАИ.

- **Вычисление разницы (Diff Engine)**:
  - Фоновый планировщик отслеживает изменения в расписании групп.
  - Детектирует 6 типов событий:
    - Отмена занятия.
    - Добавление новой пары.
    - Перенос времени или даты.
    - Изменение номера аудитории.
    - Смена преподавателя.
    - Изменение типа занятия (например, замена лекции на практику).
- **Мгновенные уведомления**:
  - Автоматическая рассылка структурированных сообщений студентам в Telegram при обнаружении изменений.
  - Фильтрация прошлых занятий: уведомления формируются только для текущих и будущих пар.
- **Управление через бота**:
  - Кнопка вызова Mini App прямо из чата.
  - Команды быстрого просмотра расписания на сегодня, завтра и неделю.
  - Переключение персональной группы и управление приемом уведомлений.

## 4. Веб-портал

Дополнительный веб-интерфейс для работы вне Telegram.

- Главная страница со строкой интерактивного поиска учебной группы.
- Быстрая генерация персональных ссылок для подключения календаря.

## 5. Производительность и серверная архитектура

- **Ядро на Rust**:
  - Асинхронный стек на базе Tokio и веб-фреймворка Axum.
  - Потребление оперативной памяти: всего ~5–10 МБ RAM при активной работе.
- **База данных SQLite**:
  - Локальное хранение без накладных расходов тяжелых СУБД.
  - Режим WAL (Write-Ahead Logging) для быстрых неблокирующих параллельных операций чтения и записи.
  - Принудительный сброс чекпоинта WAL при штатной остановке сервиса.
- **Отказоустойчивость при работе с внешним API МАИ**:
  - Короткие таймауты (5 секунд) на сетевые запросы к `public.mai.ru`, исключающие зависание рабочих потоков.
  - Автоматическое сохранение снимков в БД: если сервер МАИ временно недоступен, сервис отдает сохраненные данные.
- **HTTP-кэширование**:
  - Заголовки `Cache-Control` с директивами `max-age` и `stale-while-revalidate` для разгрузки сервера и сетевого канала.
- **Автоматизированное резервное копирование и деплой**:
  - Скрипт деплоя создает резервную копию базы данных перед каждым обновлением контейнера.
  - Автоматическое получение и продление SSL-сертификатов Let's Encrypt через Certbot.
  - Компактный Docker-образ на Alpine Linux (~25 МБ).
