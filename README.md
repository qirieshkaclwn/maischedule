# MAI Schedule Sync & Notifier

Сервис на Rust для автоматической синхронизации расписания Московского авиационного института (МАИ) с календарями (Apple Calendar на iOS / macOS, Google Calendar) по протоколу Webcal (iCalendar RFC 5545) и мгновенных уведомлений об изменениях в Telegram.

## Основные возможности

- Синхронизация по протоколу Webcal (iCalendar):
  - Персональная ссылка подписки для любой академической группы.
  - Поддержка аудиторий, преподавателей и напоминаний (Alarm).
  - Детерминированные UID событий по стандарту RFC 5545 — корректное обновление без дублирования.
  - Фиксированный часовой пояс Europe/Moscow (MSK UTC+3).
- Отслеживание изменений расписания:
  - Фоновый планировщик периодически опрашивает API МАИ.
  - Точное вычисление разницы (diff): отмена, перенос, смена аудитории, смена преподавателя, смена типа пары, добавление занятий.
  - Мгновенные уведомления подписчикам в Telegram.
- Многопользовательский режим и таблица пользователей:
  - Каждый пользователь (студент) выбирает свою академическую группу.
  - Таблица users хранит персональную группу, Telegram username, имя и настройки уведомлений.
  - Интерактивный поиск и выбор групп прямо в чате Telegram.
  - Возможность включать и отключать уведомления об изменениях.
- Каталог всех групп МАИ и фоновый сбор:
  - Автоматическая синхронизация справочника всех групп института (~935 групп).
  - Фоновый планировщик парсит и кэширует расписание всех групп.
  - Приоритетная проверка групп активных пользователей и мгновенная рассылка diff-уведомлений.
- Telegram Mini App (Web App):
  - Интерактивный просмотр расписания прямо внутри Telegram (Сегодня, Завтра, Вся неделя, чипы выбора дней).
  - Карточки пар с цветовой индикацией типа занятия (лекция, практика, лабораторная), временем, кабинетом, преподавателем и ссылками на LMS / Teams.
  - Быстрый поиск и смена группы через выдвижную панель со строкой живого поиска по всем группам МАИ.
  - Добавление календаря по Webcal в Apple Calendar и копирование ссылки на .ics.
  - Переключение уведомлений и поддержка системной светлой/темной темы оформления Telegram.
- Встроенный Telegram-бот:
  - Интерактивная кнопка меню и клавиатура для запуска Telegram Mini App.
  - Просмотр расписания на сегодня, завтра и всю текущую неделю.
  - Быстрая смена группы и поиск групп по номеру или фрагменту названия.
  - Интерактивная кнопка для подключения календаря в один клик на iPhone.
- Веб-портал со строкой поиска:
  - Интерактивный выбор любой группы из справочника МАИ с автодополнением.
  - Мгновенная генерация ссылок Webcal и HTTPS (.ics) для выбранной группы.
- Высокая производительность и низкое потребление ресурсов:
  - Написан на Rust с использованием асинхронного рантайма Tokio и HTTP-фреймворка Axum.
  - Локальная база данных SQLite (без необходимости разворачивать тяжелые СУБД).
  - Потребление оперативной памяти в рантайме: ~5–10 МБ RAM.
  - Размер Docker-образа: ~25 МБ на базе Alpine Linux.
- Надежное сохранение данных и резервное копирование:
  - База данных монтируется с хоста (./data) и полностью сохраняется между обновлениями контейнера.
  - При остановке сервиса выполняется принудительный сброс WAL-журнала (checkpoint) на диск.
  - Скрипты деплоя автоматически создают резервную копию базы данных перед каждым обновлением в каталоге backups/.



## Быстрый старт

### Требования
- Docker и Docker Compose (или Rust 1.80+ при локальной сборке).
- Токен Telegram-бота от @BotFather (для работы бота и уведомлений).

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-логин>/maischedule.git
cd maischedule
```

### 2. Настройка переменных окружения
Скопируйте шаблон конфигурации и укажите ваши параметры:

```bash
cp .env.example .env
nano .env
```

Основные параметры конфигурации:

| Переменная | Описание | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | (обязательно) |
| `BASE_URL` | Публичный URL вашего сервера (IP или домен) | `http://localhost:8000` |
| `DEFAULT_GROUP` | Учебная группа по умолчанию | `М3О-309БВ-24` |
| `PORT` | Порт HTTP-сервера | `8000` |
| `HOST` | Хост HTTP-сервера | `0.0.0.0` |
| `CHECK_INTERVAL_MINUTES` | Интервал проверки изменений расписания (в минутах) | `30` |
| `DB_PATH` | Путь к базе данных SQLite | `data/maischedule.db` |
| `TIMEZONE` | Часовой пояс расписания | `Europe/Moscow` |
| `ALERT_MINUTES_BEFORE` | Время напоминания до начала пары (в минутах) | `15` |

### 3. Запуск через Docker Compose

```bash
docker compose up -d
```

Проверка статуса:
```bash
docker compose ps
docker compose logs -f
```

## Подключение календаря

### На iPhone (Apple Calendar)
1. В Telegram-боте выполните команду `/start` и нажмите кнопку «Добавить в Календарь iPhone» (или откройте `http://<IP_сервера>:8000/subscribe/<ГРУППА>` в Safari).
2. В появившемся окне Apple Calendar нажмите «Подписаться».
3. В параметрах учетной записи установите частоту автообновления: «Каждые 15 минут».

Ручное подключение в настройках iOS:
1. Настройки -> Календарь -> Учетные записи -> Добавить учетную запись.
2. Выберите «Другое» -> «Подписной календарь».
3. Введите адрес подписки: `http://<IP_сервера>:8000/calendar/<ГРУППА>.ics`.

### В Google Calendar
1. Откройте Google Календарь в веб-версии.
2. В левой панели нажмите «+» рядом с разделом «Другие календари» -> «С URL-адреса».
3. Вставьте ссылку: `http://<IP_сервера>:8000/calendar/<ГРУППА>.ics`.

## Команды Telegram-бота

- `/start` — Главное меню, запуск Mini App и ссылка на подключение календаря.
- `/app` — Открыть интерактивное веб-приложение Telegram Mini App.
- `/group <имя>` — Выбор или смена учебной группы (например: `/group М3О-309БВ-24`). Можно также просто отправить номер группы сообщением в чат.
- `/today` — Расписание занятий на сегодня.
- `/tomorrow` — Расписание занятий на завтра.
- `/week` — Расписание на текущую учебную неделю (Пн–Сб).
- `/notifications` — Включение и отключение уведомлений об изменениях в расписании.
- `/changes` — История последних зафиксированных изменений в расписании вашей группы.
- `/check` — Ручной запуск проверки изменений расписания.
- `/link` — Ссылки Webcal и HTTPS для календаря.
- `/admin_log` — Выгрузка текстового файла с общим логом изменений по всем группам (только для администратора).
- `/help` — Справка по командам.

## HTTP API

- `GET /health` — Проверка состояния сервиса (healthcheck). Возвращает JSON со статусом и версией.
- `GET /app` — Веб-интерфейс Telegram Mini App (поддерживает параметр `?group=<название>`).
- `GET /api/schedule/:group` — Данные расписания учебной группы в формате JSON.
- `GET /api/groups` — Список всех групп МАИ в формате JSON (название, институт, курс).
- `GET /api/user/:id` — Получение настроек пользователя (текущая группа, статус уведомлений).
- `POST /api/user/group` — Сохранение выбранной группы пользователя.
- `POST /api/user/notifications` — Переключение статуса уведомлений пользователя.
- `GET /calendar/:group.ics` — Экспорт расписания в формате iCalendar (.ics) для указанной группы.
- `GET /subscribe/:group` — Страница быстрого подключения календаря для iOS с автовызовом Webcal.
- `GET /` — Веб-портал с поиском и автодополнением по всем группам МАИ.

## Деплой на удаленный сервер

Для доставки контейнера на сервер в репозитории подготовлены скрипты:

- **Windows (PowerShell):**
  ```powershell
  .\deploy.ps1 <IP_СЕРВЕРА>
  ```

- **Linux / macOS (Bash):**
  ```bash
  ./scripts/deploy.sh <IP_СЕРВЕРА>
  ```

Также настроен GitHub Actions workflow (`.github/workflows/deploy.yml`) для автоматической сборки и деплоя при `git push`.
