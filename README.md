# 🦀 MAI Schedule Sync & Notifier (Rust Edition)

Сервис на **Rust** для **автоматической синхронизации расписания МАИ с календарем (Apple Calendar на iPhone / Mac, Google Calendar)** и **мгновенных уведомлений об изменениях в Telegram**.

Переписан на Rust для максимальной производительности и ультра-низкого потребления ресурсов на слабых VPS:
- **Оперативная память в рантайме:** всего **~5–10 МБ RAM**!
- **Размер Docker-образа:** всего **~18 МБ** (на базе Alpine Linux)!
- **Нагрузка на процессор:** **~0%** в режиме ожидания.

---

## 🚀 Возможности

1. **📲 Нативная интеграция с iPhone (Apple Calendar)**:
   - Персональная ссылка подписки по протоколу **Webcal** (`webcal://` / `.ics`).
   - Настройка автообновления на iOS: каждые 15 минут.
   - Поддержка аудиторий, преподавателей, ссылок (LMS, Teams) и напоминаний (Alarm за 15 минут до начала пары).
   - Часовой пояс `Europe/Moscow` (MSK UTC+3) строго зафиксирован в формате RFC 5545.
   - Стабильные детерминированные `UID` событий — iOS корректно обновляет существующие записи без дублирования.

2. **🔔 Детектор изменений и уведомления в Telegram**:
   - Фоновый планировщик опрашивает API МАИ по расписанию.
   - Вычисляет точный diff:
     - ❌ **Отмена занятия**
     - 🔄 **Перенос занятия** (на другой день или время)
     - 🏢 **Смена аудитории**
     - 👨‍🏫 **Смена преподавателя**
     - 📚 **Смена типа пары** (лекция / практика / лабораторная)
     - ➕ **Добавление нового занятия**
   - Мгновенная рассылка понятных сообщений с эмодзи в Telegram.

3. **🤖 Встроенный Telegram-бот**:
   - `/start` — приветствие, кнопка подключения в 1 клик для iOS.
   - `/link` — отображение Webcal и HTTPS ссылок на календарь.
   - `/today` — расписание на сегодня.
   - `/tomorrow` — расписание на завтра.
   - `/week` — полное расписание на текущую учебную неделю (Пн–Сб).
   - `/group <имя>` — смена учебной группы (например, `/group М14О-101БВ-26`).
   - `/changes` — история последних изменений.
   - `/check` — ручная проверка расписания прямо сейчас.

## 🛠 Сборка на вашем компьютере и запуск на VPS

Чтобы компиляция Rust не нагружала слабый VPS и не вызывала Out-of-Memory (OOM), сборка выполняется на вашей машине, а на сервер отправляется готовый архив (~15 МБ).

### Шаг 1. Сборка образа на вашем компьютере

В терминале на вашем ПК выполните готовый скрипт:

**Windows:**
```cmd
.\scripts\build_and_export.bat
```

**Linux / macOS:**
```bash
chmod +x ./scripts/build_and_export.sh
./scripts/build_and_export.sh
```

Скрипт соберет образ под архитектуру `linux/amd64` и создаст компактный файл `maischedule.tar.gz`.

---

### Шаг 2. Копирование на VPS

Отправьте файл архива и конфигурацию на сервер:

```bash
scp maischedule.tar.gz docker-compose.yml .env.example root@<IP_VPS>:~/
```

---

### Шаг 3. Запуск на VPS

Подключитесь к VPS по SSH:

```bash
ssh root@<IP_VPS>
```

1. Настройте конфигурацию `.env`:
   ```bash
   cp .env.example .env
   nano .env
   ```
   Укажите `BOT_TOKEN` (от [@BotFather](https://t.me/BotFather)) и `BASE_URL` (IP или домен вашего VPS).

2. Загрузите образ из архива:
   ```bash
   docker load < maischedule.tar.gz
   ```

3. Запустите контейнер:
   ```bash
   docker compose up -d
   ```

4. Проверьте потребление памяти (будет всего ~5–8 МБ!):
   ```bash
   docker stats maischedule
   ```

## 📱 Как подключить календарь к iPhone

### Вариант 1: В один клик
1. Откройте адрес `http://<IP_сервера>:8000/` в браузере Safari на iPhone (или выполните команду `/start` в Telegram-боте).
2. Нажмите кнопку **«Добавить в Календарь на iPhone»**.
3. Подтвердите подписку в открывшемся окне Apple Calendar.
4. В свойствах подписки включите автообновление: **«Каждые 15 минут»**.

### Вариант 2: Вручную в Настройках iOS
1. **Настройки** ➡️ **Календарь** ➡️ **Учетные записи**.
2. **Добавить учетную запись** ➡️ **Другое** ➡️ **Подписной календарь**.
3. Вставьте ссылку: `https://<ваш-сервер>/calendar/М14О-101БВ-26.ics`.
4. Сохраните и задайте частоту обновления: **Каждые 15 минут**.
